# Titanic Visualization Assignment

## Overview

This project demonstrates data visualization using the Titanic dataset with Python, Matplotlib, and Seaborn.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Visualizations

- Countplot
- Swarmplot
- Pie Chart
- Heatmap
- Violin Plot
- Scatter Plot

## How to Run

1. Install the required libraries:
   pip install -r requirements.txt

2. Open the notebook:
   assignment-2.ipynb

3. Run all cells.
